# 高精度电子秤暑期实践培训内容

培训对象：2026级研究生  
培训周期：2026.7.22-8.14

## 一、项目速览

用4周时间，每人设计和制作一台量程约0—500g的高精度电子秤。机械敏感结构、应变片布置、惠斯通电桥、模拟放大滤波电路、STM32采集程序、数据存储/传输、标定方法和上位机均由学员完成。允许使用通用器件和开源库，但必须说明选型依据并能够独立解释。

技术链路：载荷→弹性体形变→应变片电阻变化→惠斯通电桥→仪表放大→低通滤波→ADC采样→STM32处理→串口通信→上位机显示

### 必做功能

1. 自行设计弹性体和承载平台，完成受力分析、应变估算、强度校核与加工图。
2. 完成应变片粘贴、引线焊接和惠斯通全桥组建，获得与载荷单调对应的桥路输出。
3. 设计并焊接仪表放大、偏置/参考、低通滤波和电源去耦电路（收音机散件焊接组装代替）。
4. 使用STM32完成稳定采样、去皮、标定、数字滤波、状态判断和串口通信。
5. 完成上位机实时显示、数据保存和基本曲线绘制；至少可导出CSV。
6. 完成零点、加载/卸载、多点标定、重复性、漂移、偏载和抗干扰测试。
7. 提交完整工程资料并完成现场演示、盲测和个人答辩。

### 选做与挑战功能

- 温度测量与温漂补偿；
- 偏载识别或多点结构解耦；
- 振动环境下的动态称量与稳定状态识别；
- 过载、断线、饱和和传感器异常诊断；
- 基于K-Means、SVM、决策树或BP网络的工况识别；
- 自动生成标定与性能测试报告；
- 低功耗、无线通信、结构外壳和可制造性优化。

### 验收指标

| 指标 | M0合格 | M1良好 | M2优秀 |
|------|--------|--------|--------|

| 功能完整性 | 称重、去皮、串口上传、数据保存均正常 | 增加本地显示、状态提示和参数配置 | 自动诊断、自动报告或无线扩展 |
| 量程 | 0~500g | 0~500g+120%FS过载保护 | 量程可配置或结构可替换 |
| 显示分辨率 | 0.1 g | 0.1 g且静态显示不频繁跳变 | 0.05g或更高（须用噪声数据证明有效） |
| 最大误差 | ≤±2.0g | ≤±1.0g | ≤±0.5g |
| 重复性 | 极差≤1.0g | 极差≤0.5g | 极差≤0.2g |
| 非线性 | ≤0.40%FS | ≤0.20%FS | ≤0.15%FS |
| 零点漂移(30min) | ≤±1.0g | ≤±0.5g | ≤±0.2g |
| 稳定时间 | ≤3s | ≤1.5s | ≤1.0s |
| 偏载误差 | 完成测试并解释 | ≤1.0g | ≤0.5g或可识别偏载状态 |
| 连续运行 | 2h无死机 | 4h无死机且无明显热漂 | 8h稳定运行并有异常日志 |

## 二、四周任务安排

从明天（2026年7月22日）开始-2026年8月14日结束。

### 第一周：下单采购元器件，系统学习理论

#### Day 1：采购元件、安装软件

- 根据《元器件采购清单》下单，预计3-5天到货
- 同步下载SolidWorks、Altium Designer、STM32CubeIDE、Python环境
- 建立Git仓库，创建项目目录结构

#### Day 2-3：理论学习

- 理解悬臂梁受力：σmax = 6FL/(bh²)，ε = σ_max/E
- SolidWorks建模：绘制单悬臂梁/平行梁三维模型
- 学习应变片原理：电阻变化ΔR/R = GF·ε
- 理解惠斯通电桥：四片应变片全桥接法，输出V_o ≈ V_ex·GF·ε
- 完成第一版弹性体设计草图和尺寸计算书(SolidWorks)
- 仪表放大器AD620/INA128：增益G = 1 + 49.4kΩ/R_g，计算满量程增益200-400倍
- RC低通滤波：f_c = 1/(2πRC)，目标截止频率5-20Hz
- 电源去耦：模拟地与数字地单点连接
- 用LTspice/Multisim仿真放大链路
- 完成模拟前端原理图初稿
- STM32定时器触发ADC采样，目标100-200Hz
- DMA环形缓冲，采集与处理解耦
- 串口协议设计：帧头0xAA 0x55 + 时间戳 + 原始码 + 重量 + 状态字 + CRC16
- Python上位机：PyQt或Tkinter实时显示 + CSV保存
- 完成"定时采样+串口输出"最小工程

**本周交付：**

- 采购订单截图（负责人汇总）
- 弹性体CAD模型 + 计算书
- 模拟前端原理图 + 仿真截图
- 项目方案书初稿

### 第二周：硬件设计与制作

#### Day 1-2：原理图与PCB设计

- 根据仿真结果确定最终增益电阻Rg、滤波RC参数
- 绘制完整原理图：桥路激励→仪表放大→低通滤波→ADC→STM32
- 布局洞洞板/PCB：模拟区与数字区分离，电源入口布置去耦电容
- 输出BOM清单，核对到货器件

#### Day 3：弹性体加工与试装

- 尺寸复测：用游标卡尺确认b、h、L符合设计值
- 试装承载平台、限位柱，确认加载路径（铝合金片）

#### Day 4：应变片粘贴

- 试片练习：先在废件上练习贴片，确认阻值稳定、方向正确
- 正式贴片：定位→施胶→压紧→固化
- 焊接过渡片和引线，设置应力释放弯
- 测量阻值和绝缘电阻，记录贴片位置图

#### Day 5：桥路组建与测试

- 四片按拉压交替组成全桥，检查桥臂接线
- 零载输出测量，确认接近0mV
- 轻载（如50g）测试，确认输出单调、方向正确、卸载回零
- 涂覆保护层

**本周交付：**

- 最终版原理图 + BOM + PCB图
- 弹性体实物 + 尺寸记录
- 贴片工艺卡 + 阻值记录 + 照片
- 桥路测试数据（零点、轻载输出）
- G2传感链验收表

### 第三周：代码编写与系统集成

焊接电路板，编写STM32固件和上位机，完成端到端数据闭环

#### Day 1-2：电路焊接（收音机）与静态测试

- 按原理图焊接洞洞板：先电源部分→再模拟前端→最后数字部分
- 电源测试：确认5V桥压、3.3V数字电源稳定
- 放大器测试：用已知微小电压验证增益和输出范围
- 接入桥路，测零载输出、共模电压和噪声，确认无饱和
- 记录静态噪声数据（RMS、时域波形）

#### Day 3：STM32采集固件开发

- 定时器触发ADC采样（100-200Hz），DMA传输到环形缓冲
- 原始码上传至上位机，验证采样率正确
- 实现中值滤波（抑制尖峰）+ 移动平均/IIR滤波（稳定显示）
- 状态机：初始化→预热→去皮→测量→稳定→过载→故障
- 参数存储：零点b、比例系数a存入Flash/EEPROM，带版本号和CRC

#### Day 4：标定算法与上位机

- 单点去皮：记录零载原始码，后续测量减去零点
- 两点标定：用已知砝码（如200g、500g）建立"原始码→重量"线性关系
- Python上位机：实时显示重量、稳定状态、原始码、温度
- 曲线显示：最近30-60秒原始/滤波数据
- CSV导出：含时间戳、原始码、重量、状态

#### Day 5：系统集成与G3验收

- 端到端联调：加载砝码→桥路→放大→ADC→STM32→串口→上位机
- 连续运行1小时测试：无死机、无通信丢帧
- 测试去皮、过载判断、断线检测等状态功能
- G3验收：端到端数据闭环 + 连续运行1h + 8S检查

**本周交付：**

- 焊接板实物 + 静态噪声测试数据
- 固件v1.0（Git标签）+ 上位机程序
- 通信协议文档
- G3系统集成验收表

### 第四周：调试检验与修改完善

多点标定、性能测试、故障排查、科研拓展、最终验收

#### Day 1：多点标定与静态性能

- 预热15分钟，记录环境温度和零点变化
- 加载标定：0→50→100→200→300→400→500g，每点稳定后记录≥5秒
- 卸载标定：反向逐级卸载
- 重复3个循环，计算线性度、重复性、迟滞
- 拟合最佳直线，计算各点示值误差

#### Day 2：环境试验与鲁棒性测试

- 零点漂移：空载连续记录30分钟，计算起止差和趋势
- 偏载测试：在平台中心及前后左右位置加载同一砝码
- 振动试验：轻微桌面振动，比较原始与滤波输出
- 连续运行2-4小时：记录死机、通信丢帧、热漂
- 故障注入：模拟断线、过载、饱和，验证系统反应

#### Day 3：科研拓展（选做）

- 温漂补偿：同步记录温度，建立温度-零点/增益补偿模型
- 偏载识别：多桥路或有限元分析，识别加载位置
- 振动抑制：设计数字滤波或稳定状态判定算法
- 工况识别：用K-Means/SVM识别空载/稳定/加载/振动等状态
- 自动报告：Python脚本一键生成标定曲线和性能指标

#### Day 4：故障诊断与文档整理

- 个人盲故障诊断：随机抽取已知故障，30-45分钟内定位
- 整理技术报告v1.0：系统架构、设计依据、性能数据、失败案例
- 资产盘点：设备、砝码、器件状态记录
- 数据归档：原始数据只读保存，处理数据单独存放

#### Day 5：最终验收与答辩

- 盲测：评委随机抽取砝码，操作者不知质量
- 现场演示：加载、去皮、标定、数据保存
- 个人答辩：5分钟项目介绍 + 5分钟设计依据 + 5分钟性能数据 + 10分钟问答
- 资产交接、工位清场、8S闭环
- 提交最终发布包：源代码、数据、报告、PPT

**本周交付：**

- 完整标定数据
- 性能分析报告：误差、重复性、漂移、偏载、动态响应
- 拓展任务结果（如有）
- 技术报告 + 答辩PPT + 最终发布包
- G4/G5验收表 + 个人评分表

## 三、关键注意事项

- 化学品（胶粘剂、清洗剂）查阅SDS，佩戴手套，保持通风
- 发现冒烟/异味/异常发热，立即断电上报
- 禁止直接购买成品电子秤或HX711等完整称重模块作为主方案
- 禁止修改或覆盖原始实验数据
- 禁止复制他人完整代码/图纸而不注明来源
- Git提交记录必须完整，禁止最后一天集中提交
- 关键函数和设计必须能现场解释
- 整理：每日清除无关物品
- 整顿：工具、仪器、砝码定置归位，30秒可取可还
- 清扫：清除切屑、胶渍、焊锡残渣，清扫即点检
- 清洁：标准照片、标签、清单统一，不靠临时突击
- 素养：按时参会，损坏如实报告，操作后主动归位
- 安全：PPE佩戴、限流通电、危化品密闭、通道畅通
- 节约：先小样验证再正式制作，及时关闭仪器
- 学习：每周1次改善分享
- 代码实时提交Git，数据实时上传共享盘
- 现场操作（贴片/焊接/测试）通过腾讯会议直播，远程学员同步记录
