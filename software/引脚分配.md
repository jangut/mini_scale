| :-------------- | :------- |

| **23, 35, 47**    | **GND**  |

| **8**             | 模拟地   |

---

## 3. 外设接口

### 3.1 温度传感器（ADC 采集）

| 引脚号 | 功能                   |
| :----- | :--------------------- |
| **11** | **ADC 温度传感器输入** |

> 该脚为独立模拟/数字温度传感器通道，与下文 SPI ADC 芯片无关。

---

### 3.2 SPI 接口 ADC 芯片（软件 SPI）

| 引脚号 | SPI 信号  | 说明                     |
| :----- | :-------- | :----------------------- |
| **13** | **CS**    | 片选                     |
| **14** | **CLK**   | 时钟                     |
| **15** | **DRDY**  | 数据就绪（中断/查询标志）|
| **16** | **MISO**  | 主机输入，从机输出       |
| **17** | **MOSI**  | 主机输出，从机输入       |

> ⚠️ 此模块因走线限制，固件中务必使用**软件模拟 SPI**，勿开启硬件 SPI 外设。

---

### 3.3 I²C 通信（预留显示屏）

| 引脚号      | 功能          |
| :---------- | :------------ |
| **42, 43**  | I²C（SCL/SDA）|

---

### 3.4 GPIO 输入（按键）

| 引脚号      | 功能           |
| :---------- | :------------- |

---

### 3.5 程序下载口

| 引脚号      | 功能         |
| :---------- | :----------- |
| **34, 37**  | SWD 下载口   |

---

### 3.6 串口通信

| 引脚号      | 功能          |
| :---------- | :------------ |
| **30, 31**  | UART（TX/RX） |
