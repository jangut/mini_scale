# 称重传感器上位机（定制款）

通过单片机串口实时接收称重数据，绘制折线图；当重量发生显著变化并稳定后自动
记录到右侧表格，可一键导出 CSV；底部状态栏显示当前温度、连接状态与数据速率。
程序图标使用仓库根目录的 `LOGO.png`。

界面布局（与需求示意图一致）：

```
┌──────────────────────────────┐
│     top_bar（串口/模拟/参数） │
├────────────────────┬─────────┤
│                    │   datas │
│     graph（折线图） │  记录表格│
│                    ├┬───────┬┤
│                    ││ export││
├────────────────────┴─────────┤
│ state（重量/温度/速率/记录数）│
└──────────────────────────────┘
```

## 运行

依赖已安装到 conda 的 `speech` 环境（PySide6、pyqtgraph、pyserial、numpy）。

```powershell
conda activate speech
python main.py
```

如需在其他环境安装依赖：`python -m pip install -r requirements.txt`

## 使用方法

1. 选择串口（点"刷新"扫描 COM 口）和波特率（默认 115200），点"连接"。
2. 没有硬件时，勾选 **模拟数据** 即可看到完整的称重 → 记录 → 导出流程。
3. 左侧折线图实时绘制重量曲线，红色圆点为自动记录点。
4. 右侧表格自动记录重量（时间 / 重量 / 温度），点 **导出 CSV** 保存。

## 无硬件测试

手头没有传感器/单片机时的三种测试方式：

1. **内置模拟数据**（最简单）：勾选顶栏"模拟数据"，程序内部模拟
   "放上/取下重物"的称重过程，覆盖绘图、自动记录、导出全流程。
2. **虚拟串口 + 虚拟传感器**（测真实串口链路）：安装免费虚拟串口驱动
   com0com（https://github.com/maths-robot/com0com 或官方站点），创建一对
   虚拟串口（如 COM3↔COM4），然后：
   - 终端 A 运行发送端：`python tools/fake_scale.py --port COM3`
   - 上位机选择 COM4 并连接，即可收到模拟传感器发来的 `weight,temp` 数据流
   - 可用 `--baud`、`--rate` 调整波特率与发送频率
3. **串口调试助手**：用 SSCOM / XCOM 等工具手动向虚拟串口发
   `123.45,25.6\n` 之类的行，观察上位机解析与记录。

## 串口协议（与单片机约定）

每行一条记录，逗号分隔，以换行符结尾（`\n` 或 `\r\n`）：

```
123.45,25.6     ← 重量(g), 温度(°C)
123.45          ← 仅重量（温度显示为 --）
```

- 第一列为重量，第二列（可选）为温度，单位固定 g / °C。
- 乱码行 / 非数字行会被自动跳过，不影响运行。
- 波特率需与单片机一致；建议单片机按 10~100 Hz 连续发送。

## 记录规则（变化超阈值 + 稳定确认）

- **阈值 (g)**：重量相对上次记录值的变化超过该值，才可能触发一次新记录；
  同时兼作噪声抑制，传感器抖动小于阈值时不会误记录。
- **稳定窗口 (s)**：触发后读数需**连续稳定**该时长（稳定 = 变化小于阈值），
  才确认记录一次，防止称重未稳定就记录。
- 记录后不会重复记录同一稳定值；只有再次离开该值超过阈值才会重新触发。

参数可在顶栏实时调整，修改后立即生效。

## 温度显示（来源可选）

顶栏"温度"按钮弹出**温度来源**对话框，三种来源任选其一：

- **串口**：显示单片机回传的真实温度（串口数据第二列 `weight,temp`）；
- **网络定位**：当地气温。填城市名（如"北京"）回车即生效，"IP 定位"按钮可按
  公网 IP 自动填城市（**注意**：走代理/VPN 时会定位到出口节点，可能不准，
  建议直接输城市名）。启动获取一次，之后每 10 分钟自动刷新；
- **手动设定**：直接填一个固定温度值，状态栏恒显示，记录也写入该值。

选择会自动记住，下次启动沿用。网络气温来自 Open-Meteo（免 API key），
仅为环境气温参考；若需做温度补偿或监测传感器温度，请让单片机通过串口温度列回传。
状态栏会标注当前来源（`(串口)` / `(网络·城市)` / `(手动)`）。

## 导出 CSV 格式

列：`timestamp`（年月日 时分秒.毫秒）、`weight_g`、`temp_c`（无温度时留空）。
文件以 UTF-8 BOM 编码保存，Excel 可直接打开。
